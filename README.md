# Password Strength Analyzer

A small, responsive password security project built with plain HTML, CSS, and JavaScript. It checks a password as you type and gives clear suggestions for improving it.

## Run it

Open `index.html` in a modern browser. No installation or server is required.

## Features

- Checks length, letter case, numbers, symbols, common passwords, and repeated patterns.
- Updates the strength meter and improvement tips as the password changes.
- Includes show/hide and strong example generation controls.
- Works on desktop and mobile screens.
- Keeps all analysis in the browser. It does not save or send the entered password.

## How the score works

The analyzer counts six basic checks and maps the result to a simple strength label. This is an educational estimate, not a guarantee of security. It does not check breached-password databases or replace a password manager.
